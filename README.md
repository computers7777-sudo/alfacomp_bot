# Telegram-бот магазина Alfa Comp

## 1. Supabase (5 минут)
1. Создайте проект на supabase.com.
2. **SQL Editor → New query** → вставьте весь `schema.sql` → **Run**.
   Создадутся таблицы `products` (156 товаров из CSV) и `customers` (контакты клиентов).
3. **Project Settings → API**: скопируйте **Project URL** и **anon public key**.

## 2. Токен бота
В Telegram откройте **@BotFather** → `/newbot` → скопируйте токен.

## 3. Куда вставлять ключи
Вверху `bot.py` три строки:
```python
BOT_TOKEN         = "ВСТАВЬТЕ_СЮДА_ТОКЕН_БОТА"
SUPABASE_URL      = "ВСТАВЬТЕ_СЮДА_SUPABASE_URL"
SUPABASE_ANON_KEY = "ВСТАВЬТЕ_СЮДА_SUPABASE_ANON_KEY"
```
На хостинге лучше не хранить ключи в коде, а задать одноимённые переменные окружения (см. `.env.example`).

Проверка на своём ПК: `pip install -r requirements.txt` → `python bot.py`.

## 4. Работа 24/7 (без вашего ПК)
Supabase хранит только данные — сам бот должен крутиться на сервере. Самый простой путь:
1. Загрузите папку на GitHub (приватный репозиторий, **без** реальных ключей в коде).
2. Подключите репозиторий в **Railway** / **Render** / **Fly.io** (все умеют собирать по `Dockerfile`).
   Тип сервиса — **Worker / Background Worker** (не Web Service: бот сам опрашивает Telegram, порт не нужен).
3. В настройках сервиса добавьте переменные `BOT_TOKEN`, `SUPABASE_URL`, `SUPABASE_ANON_KEY`.
4. Деплой — бот работает круглосуточно и перезапускается сам при сбое.

Альтернатива — дешёвый VPS: `docker build -t shopbot . && docker run -d --restart=always --env-file .env shopbot`.
Условия бесплатных тарифов у хостингов меняются — проверьте актуальные перед выбором.

## 5. Фото товаров
В CSV фото не было, поэтому в таблице `products` есть колонка `photo_url`.
1. Supabase → **Storage** → создайте **публичный** бакет `photos`, загрузите картинки.
2. Скопируйте публичную ссылку файла → **Table Editor → products** → вставьте в `photo_url` нужного товара.
Товары без фото показываются текстом. Каталог в боте обновляется сам каждые 5 минут.

## Как это работает
- `/start` → бот просит разрешение на контакт (кнопка Telegram «Поделиться номером») или можно «Пропустить».
- Каталог: категории → товары (по 8 на страницу) → карточка с фото и ценой → «Купить» показывает +998883203333 и @ALIBABO777.
- Клиентов бот читать не может (только записывать через защищённую функцию); `/forget` удаляет данные клиента.
- Если указать `ADMIN_CHAT_ID`, вам придут уведомления о новых контактах и нажатиях «Купить».
